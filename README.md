# todo-reminder-ai

A personal Todo List + Reminder app, built as a hands-on study project for Anthropic's Claude Certified Architect — Foundations (CCAR-F) certification. Core task management works standalone; AI features (natural-language entry, auto-categorization, daily digests, an escalation agent, and an MCP server) are layered on top, each mapped to a specific Claude architecture concept.

Status: under construction — scaffold in progress.
